# Bank Account Management System

A Java-based Bank Account Management System
developed using Object-Oriented Programming.

## Features
- Admin Login
- Customer Login
- Account Registration
- Deposit Money
- Withdraw Money
- Transfer Money
- Transaction History
- Savings and Current Accounts

## Technologies Used
- Java
- OOP
- Java Collections Framework

## Account Types
- Savings Account
- Current Account
